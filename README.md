# Acoustic Camera（自作音響カメラ）

8個のMEMSマイクとSTM32で、人の耳に聞こえない超音波（エア漏れの音など）を
カメラ画像の上に「見える」ようにする装置を、ゼロから作る記録です。

## 90日の目標（2026年10月〜12月）

**12月末の第一目標：自分で作った装置で、見えない超音波源が画面上に初めて見えた。**

精度より「動いた」を優先し、4段の階段で進めます。

| 時期 | 段 | 合格ライン |
|---|---|---|
| 10月 | シミュレーションで理解 | 複数のマイクで音源の方向が分かる理由を、自分のコードの図で説明できる |
| 11月前半 | 2〜4ch | 1 m先の音源が左／正面／右のどれかを当てる（10回中8回） |
| 11月後半 | 8ch | 1 m先の音源が2次元マップに出る（誤差30 cm以内） |
| 12月 | 超音波＋カメラ | エアダスターの噴出口の方向に、画面上でスポットが出る |

## ハードウェア

- マイコン：NUCLEO-H7A3ZI-Q（STM32H7A3、DFSDM 8ch）
- マイク：SPH0641LU4H-1 デジタルMEMSマイク変換基板 ×8（100 Hz〜80 kHz、PDM出力）

### マイク基板の寸法（実測・図面で確認）

| 項目 | 値 |
|---|---|
| 外形 | 20.0 × 15.0 mm、厚さ約1.5 mm |
| マイク穴 | 基板裏面の中央（左端から10.0 mm、下から7.5 mm） |
| 取付穴 | M3×2、間隔10.0 mm |
| ピン | 3.3 / GND / CLK / DATA / SEL |

- 4ch直線配置：最小間隔16 mm（15 mm＋すき間1 mm）
- 8chリング配置：基板が干渉しない最小直径は約60 mm（設計書の50 mmから変更）
